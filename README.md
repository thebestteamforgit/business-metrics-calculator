# Business Metrics Calculator

Приложение рассчитывает ключевые бизнес-метрики: ROI, конверсию воронки и средний чек (AOV)

## Структура проекта

- `src/`: исходный код
- `tests/`: unit-тесты
- `docs/`: документация

## Установка

Требования: Python 3.10+ и Git

```bash
git clone https://github.com/thebestteamforgit/business-metrics-calculator.git
cd business-metrics-calculator
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

## Запуск тестов

```bash
pytest tests/
```
