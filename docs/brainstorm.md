# Итоги брейншторма: калькулятор бизнес-метрик

Дата обсуждения: 14 октября 2026
Участники: Анастасия Бабанина, Андрей Проваторов, Алтхаф Аряпутра

## Выбранные метрики

### 1. ROI (возврат инвестиций)

- Формула: ROI = (Доход - Затраты) / Затраты * 100%
- Входные данные: доход (число), затраты (число, больше 0)
- Результат: процент

### 2. Конверсия воронки

- Формула: Конверсия = Число завершивших этап / Число вошедших в воронку * 100%
- Входные данные: число вошедших в воронку (целое, больше 0), число завершивших этап (целое, не больше числа вошедших)
- Результат: процент

### 3. Средний чек (AOV)

- Формула: AOV = Общая выручка / Число заказов
- Входные данные: общая выручка (число, не меньше 0), число заказов (целое, больше 0)
- Результат: сумма на один заказ

## Решения и допущения

- Все входные данные проверяются до расчёта: деление на ноль и отрицательные значения дают понятное сообщение об ошибке
- Расчёты оформляются отдельными функциями в src/, для каждой пишутся unit-тесты в tests/
- Кандидаты на следующие спринты: LTV, стоимость привлечения клиента (CAC)
